# 程序启动与参数绑定

程序启动台运行在 Electron 桌面客户端中，用于把一个本机程序的输入文件、输出文件和参数定义组织在一起。保存工程时会把绑定文件复制到生成工程；运行程序时只使用生成工程副本，不修改来源文件。

## 使用流程

1. 在左侧“资源”视图中通过系统文件选择器导入一个或多个本机文本文件。
2. 从文件列表选择文件，在中间编辑器中选中变量、值或任意文本片段。
3. 在选区上点击鼠标右键，选择“添加为输入参数”或“添加为输出参数”创建绑定。
4. 设置参数名、类型、默认值、单位和备注。输入参数的当前值可直接修改，并可恢复为默认值；输出参数只保存定位规则和参数元数据。
5. 填写程序路径、参数和工作目录。
6. 点击“运行程序”，客户端先保存生成工程，再把覆盖值写入生成工程副本。
7. 程序从生成工程内部启动，完成后从生成工程提取输出参数。

## 定位规则

变量解析不再根据 `.ccl`、`.py`、`.wbjn` 等文件扩展名切换规则。所有文本使用同一套赋值识别逻辑；扩展名只用于编辑器的语法高亮和初始语言提示。

创建绑定时可以选择独立识别模式：

- **自动**：记录当前选区的起始行、起始列和结束位置，直接按坐标定位，不判断变量名或相邻文本。
- **固定长度**：使用起止行、起止列确定精确范围。
- **分段**：按指定分隔符和从 `0` 开始的分段序号定位。
- **起始列**：从指定行的起始列定位到行尾。
- **整行**：以指定行作为完整参数。
- **多行**：使用起止行覆盖完整的多行范围。
- **不定行**：使用起始标记和结束标记定位，适合行号会变化的输出。
- **JSON 路径**：支持 `$.results[0].maximum`、`$["key"]` 等路径。
- **XML 路径**：支持 `/root/item[1]/@attribute` 和 `/root/item/text()`。
- **模式匹配**：使用正则表达式、标志、捕获组和出现序号定位。

自动和固定长度模式按原始坐标直接写回，不根据 Python 引号或变量语法自动转义。输入内容必须与选区范围及目标文件语法保持一致。

左侧栏可在“资源”和“参数”视图之间切换。参数视图按“文件 → 输入/输出 → 参数名”组织树形结构，适用于上百个参数同时浏览，并支持方向筛选和按参数名、类型、默认值、备注、文件路径或定位模式搜索。参数树只显示名称和数量，详细字段在右侧“参数属性”标签中编辑。

参数类型包括文本、数值、布尔和路径。运行程序前会校验当前输入值：数值必须使用有效数字或科学计数法，布尔值必须为 `true` 或 `false`，路径不能为空。新参数会根据选中的内容自动推断数值或布尔类型，其余默认使用文本类型。

参数属性中的“修改定位”会切换到右侧“定位规则”标签。此时可以在编辑器中拖选新内容，选区会自动切换为自动模式并更新起始/结束行列；随后点击“应用定位”保存，或点击“取消”放弃修改。底部“运行输出”面板默认折叠，仅显示运行命令、标准输出、标准错误和执行状态。

## 命令参数

参数输入遵循常见的命令行引号规则，例如：

```text
--input "case one.ccl" --material {{material_name}}
```

`{{material_name}}` 会替换为同名参数的值。程序路径和含空格的参数会在生成的命令中加引号。

## 工程目录

点击“保存工程”后选择一个父目录，客户端会创建一个包含完整配置和引用文件的工程目录：

```text
ProjectName/
  project.json
  launch.json
  parameters.json
  files/
    input.ccl
    result.txt
```

- `project.json` 保存工程元数据、版本和文件相对路径清单。
- `launch.json` 保存程序路径、启动参数和工作目录。
- `parameters.json` 保存输入输出参数、类型、默认值、单位、备注、当前值和定位器。
- `files/` 保存工程引用文件的完整内容。

点击“打开工程”并选择工程目录，即可恢复全部文件、参数和程序启动配置继续修改。工程不会封装为单个 JSON 文件。

工程目录当前使用 `schemaVersion: 3`，仍可读取 `schemaVersion: 2` 工程。

## 数据与限制

- 文件和绑定状态保存在当前客户端会话中。
- 生成工程内部以文件相对路径组织绑定文件；执行工具不会写回来源文件。
- 工作目录会作为子进程的工作目录传递给本机程序。
- 标准输出和标准错误各限制为 1 MB，程序默认超时时间为 10 分钟。
- 导入文件最大为 8 MB，不限制扩展名，但必须是可识别的文本内容。

## fa1 标准示例

程序启动台文件栏中的“加载 fa1 标准示例”会加载：

- `testData/fa1.config`：完整参数来源，共 152 个参数，其中 138 个输入、14 个输出。
- `testData/fa1-example.execution.json`：程序路径、参数和工作目录，以及 7 个文件的路径映射。
- `testData/CFX1.ccl`、`Post.cse`、`Mechanical_Thermal.py`、`Mechanical_Structural-2019.py`、`workbench.wbjn`：模块输入文件。
- `testData/fa1-example/Stress_Envelope_Summary.txt`：按原脚本制表符格式生成的结果摘要。
- `testData/fa1-example/ResultManifest.txt`：4 个自由输出结果的路径清单。

示例使用完整 Windows 路径登记文件。参数不会在示例 JSON 中重复维护，加载时直接读取 `fa1.config`。示例会将 `dataType` 映射为文本、数值、布尔或路径类型，并导入默认值和可提取的物理单位。
