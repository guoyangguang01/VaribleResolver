# Variable Studio

一个在浏览器本地运行的变量定位工作台。

## 功能

- 识别 `变量名 = 值 [单位]`，提取变量值、单位及上游上下文变量值。
- 收集 CFX/CCL 缩进块路径，并在源文本中直接定位变量值。
- 支持一次打开一个文件，内置 `.ccl`、`.cse`、`.py`、`.wbjn` 及常见文本格式。
- 针对 Python/Workbench 排除比较表达式和函数参数误识别，并支持 `.wbjn` 三引号内嵌 CCL 的路径解析。
- 用户选中的任意片段就是定位范围，可以是变量名、完整值或数组中的单个元素。
- 选中赋值行中的内容后，右侧会自动关联对应变量和结构路径。
- 保留最后一次有效选区，点击其他区域后仍可回到原定位。
- 使用 CodeMirror 6 在同一渲染层完成编辑、选区和变量高亮，避免双图层偏移。
- 数据仅在浏览器内处理，不上传到服务器。

## 启动

```bash
npm install
npm run dev
```

构建静态版本：

```bash
npm run build
```

运行变量解析与定位器的单元测试：

```bash
npm test
```

运行基于本机 Microsoft Edge 的自动化 UI 测试：

```bash
npm run test:ui
```

UI 测试会将 `testData/workbench.wbjn` 作为默认文件，并验证选区关联、原始字符串、数组局部元素和 CCL 属性路径。
